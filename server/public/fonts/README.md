# Be Vietnam Pro

Bộ chữ do Be — Nguyễn Type thiết kế riêng cho tiếng Việt, phát hành theo giấy
phép SIL Open Font License 1.1 (xem `OFL.txt`).

Các file `.woff2` ở đây là bản cắt sẵn hai bộ ký tự latin và vietnamese, lấy từ
Google Fonts. Nhúng kèm thay vì tải qua mạng để máy không có Internet vẫn hiện
đúng dấu tiếng Việt.

Sinh lại khi cần đổi trọng lượng chữ: xem phần tải font trong lịch sử dự án,
hoặc lấy trực tiếp từ https://fonts.google.com/specimen/Be+Vietnam+Pro
